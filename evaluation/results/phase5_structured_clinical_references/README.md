# Phase 5 Structured Clinical References

This folder groups the database-derived structured clinical references used as the comparison baseline for future NLP evaluation.

- `phase5_structured_clinical_references.json`: full case-level reference objects
- `phase5_structured_clinical_references.csv`: per-case tabular summary
- `phase5_structured_clinical_references.md`: Markdown summary table
- `phase5_structured_clinical_references_latex.tex`: LaTeX table for papers
- `phase5_reference_generation_summary.json`: generation statistics
- `phase5_reference_generation_report.md`: narrative report and missing-field notes

Reference snapshot:
- `reference/`: frozen copy of the Phase 5 outputs for comparison and reuse.
